# 🎟️ CampusTick - Event Management System

A full-stack event management platform for students and organizers.

## 🚀 Features
- Admin & Organizer roles
- Event creation & management (CRUD)
- Ticket booking system
- QR-based ticket validation
- Secure authentication
- No duplicate tickets

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB Atlas
- HTML, CSS, JavaScript

## 🔐 Security
- CORS enabled
- Validation checks implemented
- Unique ticket system
